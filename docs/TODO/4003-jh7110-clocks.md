# Phase 4003: JH7110 Clock/Reset Controller (Minimal)

## Status: Not Started

## Goal

Implement a minimal clock and reset driver for the JH7110 SoC — just enough to enable peripherals that Fornax needs (GMAC, MMC, PCIe). U-Boot leaves UART and basic system clocks running, so this phase is only needed before bringing up new peripherals in phases 4004+.

## Background

The JH7110 has 268 clocks and 181 resets across 6 clock domains. Linux has ~3000 lines of clock driver code. Fornax does NOT need a full clock framework — just targeted register writes to enable/deassert specific peripherals.

### Clock Register Layout

Every clock is a single 32-bit register at a fixed offset from the domain base:

| Bit | Field | Purpose |
|-----|-------|---------|
| 31 | CLK_ENABLE | Gate on (1) / off (0) |
| 30 | CLK_INVERT | Polarity inversion |
| 27:24 | MUX_SEL | Parent clock select (0-15) |
| 23:0 | DIV | Clock divider value |

### Reset Register Layout

Each domain has an assert register and a status register. Each bit controls one reset line. Write 1 to assert = hold in reset, write 0 to deassert = release.

### Domain Base Addresses

| Domain | Base | Clocks | Resets | Assert Offset | Status Offset |
|--------|------|--------|--------|---------------|---------------|
| SYSCRG | `0x13020000` | 190 | 126 | `0x2F8` | `0x308` |
| AONCRG | `0x17000000` | 14 | 8 | `0x38` | `0x3C` |
| STGCRG | `0x10230000` | 29 | 23 | `0x74` | `0x78` |

### PLLs

Three PLLs from 24 MHz oscillator (U-Boot configures these, Fornax should not touch them):
- PLL0: 1000 MHz (CPU)
- PLL1: 1066 MHz (DDR)
- PLL2: 1188 MHz (peripherals)

## Implementation

### 4003.1: Clock/Reset Primitives

Create `src/drivers/jh7110_crg.zig` with minimal operations:

```zig
const SYSCRG_BASE: u64 = 0x13020000;
const STGCRG_BASE: u64 = 0x10230000;

/// Enable a clock by setting bit 31 in its register
pub fn enableClock(domain_base: u64, reg_offset: u32) void;

/// Disable a clock by clearing bit 31
pub fn disableClock(domain_base: u64, reg_offset: u32) void;

/// Set clock divider (bits 23:0)
pub fn setDivider(domain_base: u64, reg_offset: u32, div: u24) void;

/// Deassert a reset line (clear the bit in the assert register)
pub fn deassertReset(domain_base: u64, assert_offset: u32, bit: u5) void;

/// Assert a reset line
pub fn assertReset(domain_base: u64, assert_offset: u32, bit: u5) void;

/// Wait for reset status to confirm deassert
pub fn waitResetDone(domain_base: u64, status_offset: u32, bit: u5) void;
```

### 4003.2: Peripheral Clock Tables

Define the specific clock register offsets and reset bits needed:

**For GMAC (Phase 4005):**
- SYSCRG: `GMAC1_AXI` (offset from Linux `clk-starfive-jh7110-sys.c`)
- SYSCRG: `GMAC1_AHB`
- SYSCRG: `GMAC1_TX`, `GMAC1_GTX`
- Reset: GMAC1 AXI reset, AHB reset

**For DW-MMC (Phase 4004):**
- SYSCRG: `SDIO1_AHB` (SD card controller)
- SYSCRG: `SDIO1_SDCARD`
- Reset: SDIO1 AHB reset

**For PCIe (Phase 4006):**
- STGCRG: `PCIE0_AXI_MST0`, `PCIE0_APB`, `PCIE0_TL`
- Reset: PCIe controller resets

Exact offsets to be extracted from Linux `include/dt-bindings/clock/starfive,jh7110-crg.h` and the clock driver source. Each clock ID maps to a register at `base + id * 4`.

### 4003.3: Init Sequence

Called from `kernelInit()` when board is `milkv_mars`:
1. Map CRG MMIO regions (SYSCRG, STGCRG) into kernel address space
2. Enable clocks for target peripherals
3. Deassert resets for target peripherals
4. Wait for reset status confirmation

This runs before peripheral driver init. The driver for each peripheral (4004, 4005, 4006) calls `jh7110_crg.enablePeripheral(.gmac1)` or similar.

## Notes

- U-Boot leaves many clocks enabled. Some peripherals may work without explicit clock init. Test first.
- Do NOT touch PLL0/PLL1/PLL2 — these are configured by U-Boot SPL for CPU and DDR.
- Pin muxing is handled by U-Boot for UART, SD, ethernet. Fornax should not need a pinmux driver initially.
- Clock offsets can be verified against the Mars buildroot SDK device tree.
